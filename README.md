# BatchLight

An MCP server that lets AI assistants (Claude Desktop, Claude Code, Codex, Cursor) read and edit photos in **Lightroom Classic**. It runs entirely on your own computer and is built privacy-first.

> **Status: early development. Not usable yet.** The design is in [docs/PLAN.md](docs/PLAN.md).
